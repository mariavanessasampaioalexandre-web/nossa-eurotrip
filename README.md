# Nossa Eurotrip — Vanessa & Mateus

Versão final editável do sistema da Eurotrip.

## Editável pelo próprio site
- roteiro;
- etapas da viagem;
- reservas e ingressos;
- hospedagens;
- voos;
- trens;
- valores em BRL, GBP, EUR e USD;
- cotação usada;
- status;
- prioridade;
- links;
- observações;
- lançamentos financeiros;
- meios de pagamento;
- checklist.

## Funciona localmente
Abra `index.html`.

## Para vocês dois editarem a mesma base
Use Supabase + Vercel/Netlify.

### Supabase
1. Crie um projeto.
2. Abra SQL Editor.
3. Execute `supabase.sql`.
4. Copie Project URL e anon/public key.
5. No site, abra `Publicar & sincronizar`.
6. Cole os dados.

### Publicar na Vercel
1. Crie uma conta na Vercel.
2. Crie um projeto novo.
3. Faça upload desta pasta ou conecte um repositório.
4. Deploy.
5. Abra o link publicado.
6. Configure o Supabase pela própria tela do sistema.

## Segurança
Não salve números completos de cartão, CVV, senhas ou documentos.
